# Статьи для сайта

Каждая статья — отдельный файл `.md` в этой папке. После добавления или изменения статьи запустите из корня проекта:

```powershell
node build-blog.js
```

Сборщик создаст готовые для публикации страницы в папке `blog/` и обновит её главную страницу. Папку `blog/` не редактируйте вручную: она пересоздаётся при каждой сборке.

В начале каждого файла обязательны поля:

```md
---
title: "Заголовок статьи"
description: "Краткое описание для поисковой выдачи"
date: "2026-09-01"
slug: "ponyatnyy-adres"
---
```

`slug` используйте латиницей, с дефисами. В тексте поддерживаются заголовки `##`, обычные абзацы, маркированные списки, нумерованные списки и ссылки Markdown.

Для ссылки на главную страницу сайта из статьи используйте путь `../../index.html`, например: `[Записаться](../../index.html#contacts)`.
